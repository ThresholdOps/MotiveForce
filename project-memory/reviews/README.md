# Review Records

Semantic review records preserve review results for important design artifacts.

Review records must include:

- reviewed artifact,
- reviewed commit SHA,
- review date,
- reviewer authority,
- findings,
- severity or blocking status,
- requested corrections,
- corrected commit SHA when available,
- remaining review questions,
- final review outcome.

A review record summarizes review results. It does not replace PR discussion, commit history, or merged repository content.
